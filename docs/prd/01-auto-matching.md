# 파트 1. 자동 매칭 (25점)

심사기준: "참가자 조건을 반영한 테이블 자동 매칭 구현 정도"
PRD: Part1 '매칭 조건과 우선순위'·'해결할 문제 1', 6.4 MAT-01~16, 7장 매칭 로직(7.0~7.4), 15장 예외 일부, 16장 운영 및 추적 일부
완료 조건 책임: 2, 3, 4, 5 (+11은 파트 3과 공동)

## PRD가 원하는 것

- "여러 조건과 우선순위를 반영해 4~6인 테이블을 자동 구성", "조건을 충족한 테이블은 운영자 검수 없이 자동 확정".
- "좋은 테이블을 더 빠르고 일관되게" — 같은 입력이면 같은 결과, 신청자가 늘어도 누락 없음.
- 필수 조건(Hard)과 선호 조건(Soft)을 **분리**해서 판단. 필수 조건은 절대 완화하지 않는다.
- "매칭 결과는 점수보다 설명 가능성이 먼저" — 왜 이 조합인지 운영자·참가자에게 설명 가능해야 함.
- 신청자 증가에 따라 경우의 수와 누락 가능성이 늘어나는 문제를 시스템이 해결.

## 필수 조건과 우선순위 (원문)

- 필수: 결제 완료, 참가 가능 날짜·희망 지역 일치, 4~6명, 나이 차이 8살 이내, 차단·신고·비선호 관계 없음.
- 선호(우선순위 순): 1 연령대(나이차) → 2 성비 → 3 MBTI 궁합 → 4 관심사 → 5 만나고 싶은 사람의 성향, + 새로운 사람 비율(이전 만남 최소화).
- 자동 확정 기준: 필수 전체 충족 + 운영자가 정한 최소 매칭 점수 이상. 선호가 완벽하지 않아도 최소 점수 이상이면 확정, 미만이면 재배치 또는 대체 일정.

## 처리 순서 (7.1) — 이 순서대로 돌아가는지 본다

1 마감 시각 스케줄러 자동 실행 → 2 결제 완료·유효 신청만 후보 → 3 날짜·지역 겹치는 사람끼리 후보군 → 4 차단·신고·비선호 조합 먼저 제외 → 5 나이차 8살 이내 4~6인 조합 생성 → 6 성비·MBTI·관심사·희망 성향·이전 만남 평가로 전체 최적화 → 7 4명 미만 해제 후 재배치 → 8 7명 이상 분리, 미완성 병합 → 9 재배치 후 전체 재검증 → 10 통과 테이블 자동 확정 → 11 확정과 동시에 단체방·식당·안내 예약 → 12 미배치자에게 다른 일정·지역 추천 → 13 이동 시 결제 유지, 환불 시 원결제수단 → 14 자동 해결 안 된 예외만 운영자.

## 재배치 우선순위 (7.4)

1 같은 날짜·같은 지역 → 2 같은 날짜·다른 선택 지역 → 3 다른 선택 날짜·같은 지역 → 4 다른 선택 날짜·다른 선택 지역 → 5 선택 안 한 모집 일정 추천(동의 후 이동) → 6 이동 원치 않으면 보관·환불.
같은 사용자를 동시에 두 테이블에 넣지 않는다. 재배치 완료 후에만 확정.

## 매칭 원칙 (7.3)

- 정상 흐름에서 운영자 검수·수동 확정 요구 없음.
- 4명 미만 테이블은 **절대** 확정 안 함.
- 재배치는 사용자가 동의한 날짜·지역 범위를 벗어나지 않음.
- 필수 조건을 완화해 억지로 만들지 않음.
- 이동·환불은 시스템이 아니라 참가자가 선택.
- 일정 이동 중 결제 중복 승인 없음.
- 같은 매칭 작업이 여러 번 실행돼도 중복 테이블·환불·단체방 없음(멱등성).

## 매칭 결과에 반드시 표시 (7.2) — 어드민 매칭 모니터/테이블 상세에서 확인

테이블 인원수 / 참가자별 희망 날짜·지역 충족 여부 / 최고·최저 연령과 차이 / 성비 / MBTI 구성 / 공통 관심사 / 참가자별 희망 상대 조건 충족 여부 / 이전 만남 여부 / 차단·비선호 충돌 여부 / 추천 점수 또는 조건별 평가 / 자동 재배치 횟수와 최종 배치 사유 / 자동 확정 또는 매칭 실패 시각.

## 기록 (16장)

자동 매칭 버전, 적용 기준, 생성·분리·병합·재배치·확정 결과(MatchRun: 실행 시각, 대상 회차, 후보자 수, 결과, 실패 사유, 알고리즘 버전).

## 흔한 함정

- 테스트가 "통과"하지만 실제 배포 cron이 꺼져 있음.
- 재배치가 고르지 않은 지역까지 넘어감.
- 선호 점수에 연령대가 빠져 있고 나이차를 필수로만 씀(우선순위 1의 "연령대"는 선호 점수에도 반영돼야 함).
- 확정 후 단체방 생성 실패 시 테이블이 반쯤 확정된 상태로 남음.
