# 시연용 식당 12곳

서울 네 동네(홍대·합정·연남 / 잠실·송파 / 강남·역삼·선릉 / 을지로·종로·광화문)에 세 곳씩, 모든 칸(업종·주소·가격대·평점·리뷰 수·예약 채널·예약 페이지·전화·좌석)을 채운 시연 데이터다. 식당 이름과 전화번호는 시연용 가상 값이고, 주소는 그 동네의 실제 도로명이다.

- `우연한식탁_시연식당_12곳.xlsx`: 어드민 > 식당 관리 > 엑셀로 올리기에 그대로 올린다. 같은 동네·같은 이름인 기존 8곳은 고쳐지고 4곳이 새로 생긴다.
- `photos/`: 식당 대표 사진 12장(파일 이름 = 식당 이름). 어드민 > 식당 관리 > 사진 여러 장 올리기로 한 번에 올린다. ChatGPT 이미지 생성으로 만든 그림이라 실제 식당 사진이 아니다(저작권 문제 없음, 2026-10-18 생성).

로컬 시뮬레이션 DB에서 엑셀 12줄(새로 4·고침 8)과 사진 12장이 모두 들어가고, 참가자 테이블 화면에 사진·업종이 보이는 것까지 확인했다.
