# 어드민 표 규칙과 가로 스크롤 화면

2026-10-20. 신청자 표에서 프로필·결제 배지 칸이 좁아져 배지가 두 줄로 깨지던 문제(성효님 제보)를 계기로, 어드민 표 전체에 같은 규칙을 둔다.
"칸을 찌그러뜨리지 말고, 표를 옆으로 넘긴다."

## 규칙

| 무엇 | 어떻게 | 어디에 |
|---|---|---|
| 표 상자 | 표는 늘 가로 스크롤 상자 안에 둔다. 새 표는 `TableScroll`로 감싼다 | `src/components/table-scroll.tsx` |
| 표 폭 | `table` + 화면별 `min-w-[…]`(최소 폭). 칸 내용이 더 넓으면 표가 그만큼 넓어지고 상자 안에서 옆으로 넘어간다 | `admin-classes.ts` |
| 머리 칸 | 줄을 바꾸지 않는다 | `th`에 `whitespace-nowrap`, CSS `.admin-main th` |
| 배지(Pill·Badge) | 어디서든 줄을 바꾸지 않는다 | `Pill`에 `whitespace-nowrap` |
| 이름·시각·금액·숫자·버튼 | 한 줄로. `tdNowrap`을 쓴다 | `admin-classes.ts`, CSS `.admin-main td.tabular-nums`, `td button` |
| 긴 글(주소·사유·바뀐 내용) | 낱말 단위로만 줄을 바꾼다(낱말 중간에서 끊지 않음, `break-keep`). 칸에 최소·최대 폭을 준다. `tdText`를 쓴다 | `admin-classes.ts`, CSS `.admin-main td` |
| 여러 개를 이은 값(동네 목록) | 하나하나는 `whitespace-nowrap`, 사이(` · `)에서만 줄을 바꾼다 | 신청자 표 '희망 동네' |
| 배지 옆 덧말 | 배지 옆이 아니라 배지 아래 줄에 둔다(재배치 1번, 이용권 보관 등) | 신청자 표 '매칭' |

공통 CSS는 `src/app/globals.css`의 `.admin-main` 아래에 있다. 다른 사람이 만든 표도 CSS만으로 머리 칸·배지·숫자 칸은 줄이 안 바뀌고, 긴 글은 낱말 단위로 넘어간다.

## 옆으로 밀어서 더 보기 (`TableScroll`)

- 표가 실제로 상자보다 넓을 때만 표 위 오른쪽에 "옆으로 밀어서 더 보기 >"가 뜨고, 더 볼 쪽 가장자리에 흐린 그림자가 생긴다. 끝까지 밀면 오른쪽 그림자는 사라지고 왼쪽 그림자가 생긴다.
- 넘칠 때는 상자에 키보드로 들어갈 수 있고(←→로 넘김), 화면 읽기에는 "○○ 표, 옆으로 밀어서 더 볼 수 있어요"로 읽힌다.
- 넘침 판단은 `src/lib/ui-geometry.ts`의 `scrollState`(테스트 있음).

## 가로 스크롤이 있는 화면

넓은 화면(1280px)에서도 넘치는 표와, 휴대폰(390px)에서만 넘치는 표를 나눠 적는다. 2026-10-20 시뮬레이션 데이터로 화면을 열어 잰 값이고, '확인 못 함'은 그날 화면을 열지 못한 곳이다.

표가 아닌 가로 스크롤: 어드민 위 메뉴(휴대폰), 예외 처리함·회차 화면의 탭 줄. 이건 탭이라 안내 띠를 달지 않는다.

가로 스크롤이 없는 표: 신청 상세 `/admin/applicants/[id]`의 '받은 알림'(세 칸, 알림 제목은 말줄임).
