# 운영사 Q&A 답변 (2026-10-16, Blaybus 공지)

PRD에 없던 값 중 **운영사가 답을 준 것**은 이제 PRD와 같은 근거로 본다. 평가 에이전트는 이 문서도 함께 읽고, 아래 'Q 확인 항목'을 자기 파트 합격 기준에 더해 채점한다.
"직접 정하세요"라고 답한 항목은 성효님이 정한 값을 따른다. 아직 안 정했으면 '정할 것'으로 남기고 점수에 넣지 않는다.

## 확정된 값 (그대로 따른다)

| 주제 | 운영사 답 |
|---|---|
| 앱 형태 | 설치형 앱이 아니라 **웹앱**. 모바일 웹브라우저에서 링크로 접속. 심사는 제출한 배포 링크로 |
| 환불 불가 시점 | 현재 **화요일 자정(24:00) 이후 환불 불가**. 매칭 마감을 이 시점과 같게 둘지는 우리가 정함 |
| 1회권 | **9,900원** |
| 멤버십 | **1개월 35,000원 / 3개월 75,000원 / 6개월 120,000원** |
| 멤버십 횟수 | 기간 안에 **횟수 제한 없이** 참여 |
| 멤버십 매칭 실패 | **실패한 횟수만큼 이용 기한 연장** |
| 운영 지역 | 지금은 **서울 4곳(홍대·잠실·강남·을지로)**. 초반엔 서울에 집중하고 서울 밖은 나중에 운영. 앱에 넣을지는 우리 판단 |
| 식당 확보 기준 | **리뷰 평점이 좋고 예약이 가능한 곳** |
| 운영자 사전 검토 | **넣지 않는다.** PRD대로 검토 없이 자동 확정 |
| 로고 | 원본 없음. 비슷하게 재현해 써도 됨 |
| 문의·운영 로그 | 제공 안 함 |

## 우리가 정해야 하는 것 (운영사: "PRD 원칙 안에서 직접 정하세요")

| 주제 | 지켜야 할 원칙 | 현재 상태 |
|---|---|---|
| 당일 취소 | PRD §7.3, §15 | 앱에서 막음("당일 취소는 할 수 없어요") |
| 노쇼 제한 기준·자동/수동·이용권 차감 | SAF-02, §15 | 문구만 있고 횟수 기준·자동 제한 없음 → **정할 것** |
| 확정 후 취소로 3명 남음 | 필수 조건은 완화하지 않음, 일정 이동·환불은 참가자가 선택 | 대기자 충원 → 다른 테이블 합류 → 안 되면 매칭 실패 화면(`attendance.ts`) |
| 성비 치우침(한 성별만, 한 명만 다른 성별) | 성비는 선호 조건(§7.0) | 점수로만 반영, 막지 않음 → 기준을 문서에 적을 것 |
| MBTI 궁합 | 기준표 없음 | `score.ts`의 자체 기준 → 문서에 적을 것 |
| 매칭 마감 = 환불 불가 시점? | 우리가 정함 | **정할 것** |

## 지금 구현과 다른 점 (2026-10-16 기준, 고칠 것)

- 가격: 1회권 29,000원, '구독 3회권' 75,000원 → 1회권 9,900원 + 기간제 멤버십 3종으로 바꿔야 함(`constants.ts`, `passes.pass_type`, 결제·차감 로직).
- 환불 기준: '모임 48시간 전' → '모임 주 화요일 24:00'(금요일 모임이면 이틀 전 0시와 같음).
- 멤버십: 횟수 차감 구조 → 기간 안 무제한, 실패 시 기한 연장.
- 기본 지역: 성수·강남·홍대·여의도 → 홍대·잠실·강남·을지로(`DEFAULT_REGIONS`, 시드).
- 식당: 평점·예약 가능 필드 없음.
- 노쇼 기준 미정.
