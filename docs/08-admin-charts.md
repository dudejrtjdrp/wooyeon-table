# 어드민 차트 규칙 (운영 지표 화면)

2026-10-20. 운영 지표(`/admin/metrics`)를 시안 A(먼저 볼 카드 → 깔때기 → 묶음 목록 → 상세 모달)로 다시 만들면서 차트 라이브러리를 들였다.

## 라이브러리: Recharts 3.10.1

| 후보 | 판단 |
|---|---|
| **Recharts 3** | 채택. React 19를 peer로 공식 지원, shadcn 차트의 바탕이라 자료가 많다. `"use client"` 컴포넌트에서 바로 쓰고, `responsive` 속성으로 래퍼 없이 폭을 따른다. 키보드(←→)로 막대를 옮기며 툴팁을 보는 접근성 층이 기본으로 켜져 있다. 쓰는 것만 가져가 번들 부담이 크지 않다(이 화면 전용, 클라이언트 차트 두 개). |
| Tremor | 제외. `@tremor/react`는 peer가 React 18이고 Tailwind v3 설정을 전제로 한다(우리는 React 19·Tailwind v4). 내부도 Recharts라 직접 쓰는 게 낫다. |
| Nivo | 제외. 기능은 넉넉하지만 d3 여러 패키지와 react-spring을 함께 들여 와 스파크라인·막대 몇 개에 비해 무겁다. |
| visx | 제외. 4.0에서 React 19를 받지만 저수준 도구라 축·툴팁·키보드 이동을 다 손으로 짜야 한다. |

## 색 (src/lib/chart-colors.ts)

- `.admin-theme` 토큰에서 뽑았다. SVG 속성에는 CSS 변수를 못 쓰므로 값으로 둔다. 토큰을 바꾸면 여기도 같이 바꾼다.
- 높을수록 좋은 지표 = `--accent`(#1e5e45), 낮을수록 좋은 지표(노쇼율·개입률·운영 시간·노쇼 후보) = `--danger`(#c2412d). 색만으로 알리지 않고 '낮을수록 좋음' 배지·글을 함께 둔다. 두 색은 한 차트에 같이 나오지 않는다.
- 깔때기 단계는 accent 한 색의 밝기 단계(`FUNNEL`). dataviz 검사(`validate_palette.js --ordinal`) 통과: 밝기 단조, 단계 간격 충분, 가장 연한 색도 흰 바탕 대비 2.3:1.
- 회차를 골랐을 때 나머지 회차 막대는 같은 색의 연한 단계(`accentDim`·`dangerDim`, 대비 2:1 넘김). 값은 아래 표에 다 있다.
- 지난 회차 대비: 화살표는 숫자 방향, 색은 좋아졌는지(지표 방향에 따라)다. 노쇼율이 내려가면 ↘ 초록.

## 모양·접근성

- 선 2px, 끝점 지름 8px + 흰 테두리 2px, 막대 최대 24px·윗모서리 4px, 눈금선은 실선 한 줄.
- 카드 안 스파크라인은 카드 자체가 버튼이라 초점을 받지 않는다(마우스 툴팁만). 같은 내용을 화면 읽기용 문장으로 둔다.
- 모달 막대 차트는 키보드로 막대를 옮길 수 있고, 같은 값이 바로 아래 표에 있다(툴팁에만 있는 숫자는 없다).
- 분모가 0인 회차·지표는 '아직 데이터 없음'. 막대를 그리지 않는다.

## 데이터

- 지표 정의·계산은 `computeMetrics` 그대로. 회차별 값은 `metricSeries`가 회차마다 `computeMetrics(input, 회차)`를 돌려 모은다(`src/lib/metrics-series.ts`, 테스트 있음). 신청이 하나도 없는 회차는 뺀다.
- 깔때기 인원은 지표 분자(제출한 신청·결제 완료·테이블 확정·체크인·후기 제출)를 그대로 쓴다.
